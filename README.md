## ✦ Sobre mim

Sou **Isabel dos Santos Neves**, desenvolvedora **Front-end UX/UI**.

Trabalho com **HTML, CSS, JavaScript e Figma**, unindo desenvolvimento de interfaces e cuidado com a experiência visual.

Gosto de construir páginas com uma estética limpa, delicada e funcional, dando atenção aos detalhes que tornam uma interface mais clara e agradável de usar.
